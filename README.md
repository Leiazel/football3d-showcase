# Football 3D Studio — Galería 360°

Demostración interactiva de cabezas 3D generadas a partir de 4 vistas fotográficas con **Hunyuan3D 2.0** (geometría + texturizado PBR realista) y procesamiento automatizado en **Google Colab + Drive**.

### Características
- **Vista interactiva 360° (Desktop y Mobile):** arrastrá con el mouse o el dedo para girar cada modelo, seleccioná entre 11 jugadores y alterná entre **Suavizado (`S`)**, **Malla Original**, **Wireframe (`W`)**, **Auto-Giro (`Espacio`)** y **Modo Limpio (`H`)**.
- **Sin archivos `.glb` públicos:** los modelos originales permanecen privados; el sitio utiliza secuencias pre-renderizadas de 24 ángulos en formato `.webp`.
