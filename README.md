# Football 3D Studio — Visor 360° Protegido

Demostración interactiva de cabezas 3D generadas a partir de 4 vistas fotográficas con **Hunyuan3D 2.0** (geometría + texturizado PBR realista) y procesamiento automatizado en **Google Colab + Drive**.

### Arquitectura de protección
- **Sin archivos `.glb` públicos:** los modelos originales permanecen privados. El sitio muestra secuencias interactivas de 24 ángulos (360°) renderizadas en tres capas (`Suavizado PBR`, `Malla Original` y `Wireframe`).
- **Controles:** arrastrá con el mouse o dedo para girar 360°, alterná entre **Suavizado (`S`)**, **Wireframe (`W`)**, **Auto-Giro (`Espacio`)**, **Modo Video (`H`)** y **Grabar Showreel (`.webm`)**.
